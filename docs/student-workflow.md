# Student Workflow

## Student Dashboard

The Student Dashboard will display:

- Assigned scenarios
- Scenario difficulty
- Due date
- Attempt status
- Active lab environment
- SSH connection information
- Previous attempts

## Lab Workflow

1. Student selects an assigned scenario.
2. Student clicks Launch Lab.
3. DNE starts the lab environment.
4. DNE displays the SSH connection command.
5. Student copies the command.
6. Student opens their own terminal.
7. Student connects to the lab through SSH.
8. Student troubleshoots the network.
9. Student returns to the DNE website.
10. Student enters the root cause and fix applied.
11. Student submits the attempt for validation.

## Lab Page

The lab page will display:

- Problem ticket
- SSH connection information
- Copy SSH command button
- Hint controls
- Reset Lab button
- Attempt progress
- Root cause submission
- Fix applied submission
- Submit for Validation button

DNE will not display suggested diagnostic commands on the lab screen.
Students are expected to determine which troubleshooting tools to use.
