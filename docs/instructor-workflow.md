# Instructor Workflow

## Instructor Dashboard

The Instructor Dashboard will provide access to:

- Scenario Library
- Assignments
- Active lab environments
- Student progress
- Attempt review

## Scenario Management

Instructors will be able to create reusable troubleshooting scenarios.

Initial scenario creation will use a form/template instead of a full
drag-and-drop topology editor.

Possible scenario fields include:

- Scenario title
- Difficulty
- Problem ticket
- Network components
- Fault type
- Hints
- Validation rules

## Student Progress Monitoring

The instructor should be able to view high-level attempt progress.

Sprint 1 progress events may include:

- Lab launched
- SSH connected
- Hint requested
- Lab reset
- Validation attempted
- Validation failed
- Validation passed
- Diagnosis submitted

Detailed command recording is not required for the initial prototype.

## Attempt Review

The instructor will be able to review:

- Student
- Scenario
- Attempt status
- Time spent
- Hints used
- Validation result
- Student diagnosis
- Student solution
